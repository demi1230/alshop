# AlShop - Монголын Орчин Үеийн Электрон Худалдааны Платформ

AlShop нь Ruby on Rails дээр суурилсан орчин үеийн электрон худалдааны платформ юм. Эрүүлхэн архитектур зарчимд тулгуурлан тоо төлөвлөгөөт бүтцээр эмхэтгэгдсэн, ангилалын шатлалт система, урьдчилсан шүүлтүүр, мобайл-ээс-анхны эсэргүүцэхгүй дизайнтай.

## 🎯 Онцлог Шинж

### Бүтээгдэхүүний Каталог
- **Шатлалтат Ангилал** - Үндсэн ба дэд ангилалаар уян хатан байдлаар ангилах
- **Дэвшилтэт Шүүлтүүр** - Ангилал, брэнд, үнийн хүрээ, хямдралаар шүүлтүүлэх
- **Бүрэн Текст Хайлт** - Бүтээгдэхүүний нэрээр шуу дүүрэн хайлт
- **Мобайл-ээс-анхны Дизайн** - Tailwind CSS ашигласан (1/2/3/4 багана)
- **Хуудасжуулалт** - Сайтар хуудасжуулалтын нэмэлт

### Худалдан авалтын Туршлага
- **Динамик Ангилалын Сонголт** - Stimulus Fetch API ашигласан дэд ангилалын автоматчилсан ачалт
- **Үнийн Хүрээ Шүүлтүүр** - Минимум/максимум үнээр шүүлтүүлэх
- **Брэндийн Сонголт** - Одоогийн ангилалд байгаа брэндээр шүүлтүүлэх
- **Эрэмбэлэх Сонголт** - Үнээр эсвэл нэрээр эрэмбэлэх
- **Худалдан авалтын Сагс** - Сессион-ээс-анхны сагс системтэй

### Админ Панел
- **Бүтээгдэхүүн Удирдлага** - Үүүлэх, засах, устгах үйлдэл
- **Ангилал Удирдлага** - Шатлалтат ангилал үүүлэх
- **Үнийн Дүрмүүд** - Хямдрал болон үнийн дүрмийг удирдах
- **Үйлчилгээ Удирдлага** - Үйлчилгээ болон түүний биелүүлэлтийг удирдах
- **Захиалга Удирдлага** - Захиалгыг харах болон удирдах

## 🛠️ Технологийн Багц

### Арын Талын (Backend)
- **Rails 8.1.2** - Хамгийн сүүлийн хувилбарын Rails
- **Ruby 3.4.8** - Орчин үеийн Ruby хэл
- **SQLite 3** - Өгөгдлийн сан
- **Devise** - Хэрэглэгчийн нэвтрэлт
- **Pundit** - Эрхийн удирдлага

### Урдын Талын (Frontend)
- **Tailwind CSS 4.4** - Дизайн нэмэлт
- **Hotwire Turbo** - Хурдан хуудасны солигдол
- **Stimulus JS** - Интерактивн frameworkнь
- **will_paginate** - Хуудасжуулалт нэмэлт

### Суурь Сүлжээ (Infrastructure)
- **Docker** - Контейнер хэрэгслэл
- **Kamal** - Docker нэвтрүүлэх хэрэгслэл
- **Puma** - Веб сервер
- **Thruster** - HTTP кешинг ба сжатие

## 📋 Шаардлага

- Ruby 3.4.8 ба түүнээс дээш хувилбар
- SQLite 3
- Node.js 18+ (JavaScript эмхэтгэлэлд зориулсан)
- Docker (контейнерчилсэн нэвтрүүлэлтээр)

## 🚀 Түргэн Эхлэл

### Орон Нутгийн Хөгжүүлэлтийн Сетап

#### 1. Репо Хуулах
```bash
git clone https://github.com/demi1230/alshop.git
cd alshop
```

#### 2. Хамаарлыг Суулгах
```bash
bundle install
npm install
```

#### 3. Өгөгдлийн Сан Бэлтгэх
```bash
rails db:create
rails db:migrate
rails db:seed
```

Мэдээлэл суулгах файл үүнийг үүүлнэ:
- 10 туршилтын хэрэглэгч (янз бүрийн дүрэм)
- 20 бүтээгдэхүүн (5 ангилалд)
- 10 үйлчилгээ
- Үнийн дүрмүүд болон хямдралууд
- 20 туршилтын захиалга

#### 4. Хөгжүүлэлтийн Серверийг Эхлүүлэх
```bash
./bin/dev
```

Үүнийг ажиллуулна:
- Rails сервер `http://localhost:3000`-д
- Tailwind CSS ажигла програм
- Stimulus халуун ачалт

`http://localhost:3000`-г браузеррүүдээ нээнэ үү.

#### 5. Админ Нэвтрэлт
```
Имэйл: admin@example.com
Нууц үг: password123
```

Админ панел `/admin/dashboard`-д байна.

### Орчин Хувьсагчид

`.env` файл (эсвэл `.env.local` орон нутгийн дарахын төлөө) үүүлнэ үү:

```bash
# Rails Тохиргоо
RAILS_ENV=development
RAILS_LOG_TO_STDOUT=true

# Өгөгдлийн Сан (SQLite анхны, тохиргоо хэрэггүй)
# Үйлдвэрлэл дээр Postgres ашигла

# Сессионы Нууц
SECRET_KEY_BASE=<сетап явагдах үед үүслэх>

# Имэйл (сонголтууд, dev-ээр letter_opener ашигла)
MAIL_HOST=localhost
MAIL_PORT=3000
```

## 🎨 Онцлог Дэлгэрэнгүй

### Шатлалтат Ангилал

Ангилал нь нас хүртлээрийн харьцаагаар уян хатан байдлаар ангиллаж болно:

```
Электроник
├── Ухаалаг Утас
│   ├── iPhone
│   └── Samsung Утас
└── Зөөврийн Компьютер
    ├── Тоглоомын Компьютер
    └── Ултра Номруулж
```

**Ангилал Удирдах:**
```ruby
# Үндсэн ангилал үүүлэх
cat = Category.create!(name: "Электроник", category_type: "product")

# Дэд ангилал үүүлэх
subcategory = Category.create!(
  name: "Ухаалаг Утас",
  category_type: "product",
  parent: cat
)

# Бүх урд үерүүлэх
all_products = Product.in_category_tree(cat.id)
```

### Бүтээгдэхүүний Шүүлтүүр & Хайлт

Бүтээгдэхүүний жагсаалтын хуудас дараахыг дэмждэг:

1. **Ангилалын Шүүлтүүр** - Уй нэрийн өмхөө сонголт
2. **Брэндийн Шүүлтүүр** - Одоогийн ангилалд байгаа брэндүүд
3. **Үнийн Хүрээ** - Минимум/максимум үнээр шүүлтүүлэх
4. **Хямдралын Шүүлтүүр** - Зөвхөн хямдралтай хэмжээ
5. **Хайлт** - Сарнай үүрийн хайлт

**API Ашигла:**
```bash
# Ангилалаар шүүлтүүлэх
GET /api/products?category_id=5

# Хайлт болон шүүлтүүлэх
GET /api/products?q=компьютер&min_price=500000&max_price=2000000

# Үнээр эрэмбэлэх
GET /api/products?sort=price_asc

# Хуудасжуулалт
GET /api/products?page=2&per_page=20
```

### Stimulus Удирдагчид

Хоёр сайл Stimulus удирдагч урдын талын интерактивт даваа:

#### ProductFilterController
- Ангилал солигдол үеийн форм автоматчилсан нэвтрүүлэлт
- Хайлтын оруулалт сарнай үүрийн (500 мс анхны)
- Шүүлтүүр сайтсар төлөв хадгалалт

#### CategoryFilterController
- Fetch API дээр дэд ангилал ачалт
- Динамик dropdown сүүнрүүлэлт
- Үндсэн ангилал сонгогдоогүй үеийн дэд ангилал идэвхүүлэлт
